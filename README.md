# Programming I coursework

A collection of introductory Java programming exercises. It includes console games (card games and tic-tac-toe), score files, and experiments with an agenda, contacts and utility menus. The repository preserves coursework iterations rather than a single finished application.

## Repository layout

- `juegosdecartas/` and `JuegosDeCartasTerminado/`: card-game implementations and score files.
- `tresenraya.java`: tic-tac-toe exercise.
- `ordenador/`: agenda, calculator, contacts and other menu experiments.
- Root-level `*.java` files: additional versions and experiments.

The repository also contains compiled files, notes and duplicate source versions. Some code references machine-specific paths such as `E:/JuegosDeCartas/`, so a clean clone is not a reproducible build. No Maven or Gradle project, automated tests or verified one-command run procedure is provided. Inspect and adapt an individual exercise before compiling it with a compatible JDK. This repository is kept as an academic record, not as a portfolio-ready software product.
